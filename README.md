# 📝 Blog Application

A full-stack blog application built using the MERN stack that allows users to register, log in, create blog posts, view blogs, and manage their content.

## 🚀 Features

- User Registration and Login
- Secure Authentication using JWT
- Create and Publish Blog Posts
- View Blog Posts
- Edit and Delete Blogs
- Upload Images with Blog Posts
- User Profile Management
- Responsive User Interface
- MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JSON Web Tokens (JWT)

### Other Tools
- Multer for Image Uploads
- Git and GitHub for Version Control
- Render for Deployment
